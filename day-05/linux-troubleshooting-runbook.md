**Command 1 : uname -a ->** uname is used to display information about the Linux system and kernel.

ubuntu@ip-172-31-17-118:~/90DaysOfDevOps-PersonalWork/day-05$ uname -a
Linux ip-172-31-17-118 7.0.0-1010-aws #10-Ubuntu SMP PREEMPT Thu Jul 23 02:06:04 UTC 2026 x86_64 GNU/Linux

| Part               | Meaning                      |
| ------------------ | ---------------------------- |
| `Linux`            | Operating system/kernel name |
| `ip-172-31-17-118` | Hostname                     |
| `7.0.0-1010-aws`   | Kernel version               |
| `#10-Ubuntu`       | Kernel build information     |
| `x86_64`           | Machine architecture         |
| `GNU/Linux`        | Operating system             |
